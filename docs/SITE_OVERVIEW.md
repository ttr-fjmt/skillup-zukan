## 1. どんなサイトか

- **URL**：https://skillup-zukan.net/
- **中身**：プログラミング・Webデザイン・語学・資格などの**講座・スクールを比べられる図鑑**
- **位置づけ**：図鑑シリーズの3サイト目（転職エージェント図鑑・フリーランス案件図鑑と同じ作り）
- **収益**：Google AdSense の広告＋提携（アフィリエイト）講座
- **ブランド色**：アンバー／オレンジ（#E67E22）。姉妹サイトとは意図的に色を分けている

サイトは大きく4つの部分でできています。

| 部分 | URL | 何が見られるか |
| --- | --- | --- |
| 一覧・トップ | `/` | 掲載中の講座をジャンルごとに並べた入口。おすすめ枠・広告枠もここ |
| 講座の詳細 | `/school/<講座ID>/` | 1講座ぶんの料金・期間・受講形式・特徴。**193ページ** |
| ジャンル別 | `/category/<ジャンル>/` | 8ジャンルぶんの一覧ページ |
| 学び直しガイド | `/guide/` | 記事3本（下記） |

そのほかに「よくある質問」（`/faq.html`）、「プライバシーポリシー」（`/privacy.html`）があります。

## 3. 毎日・毎週、自動で動いていること

| いつ | 何が動くか | 中身 |
| --- | --- | --- |
| 毎日 JST 5:00 | `discover-schools.yml` | AIのWeb検索で新しい講座を探し、実在を確認して掲載。そのあと詳細ページ・サイトマップまで作り直してコミット |

## 4. データの作り方：「二段階で確かめる」

このサイトの一番の特徴は、**AIの言うことをそのまま信じない**ことです。

1. **探す**：AIのWeb検索で、ジャンルごとに候補を挙げてもらう
2. **確かめる**：候補の**公式サイトに実際にアクセスし、そのページの本文に講座名が本当に書いてあるか**を機械的に照合する

ここを通らなかった候補は掲載しません。さらに、AIが読み取った内容（料金・期間・特徴・都道府県など）も、
**ひとつずつ「本文にその言葉が実在するか」を照合**してから保存します。

なぜここまでやるかというと、実際に次のような間違いが起きたからです。

| 起きたこと | どう直したか |
| --- | --- |
| フッターの英語表記から運営会社名を作ってしまった（3件中3件） | 本文に一字一句無ければ空欄にする |
| 「転職成功率99%」を中立的な特徴として掲載してしまった | 検証できない実績・最上級・保証の文言を自動で除外 |
| 会社の**本社住所**を通学拠点として載せてしまった | 通学拠点の根拠がある都道府県だけ残す |
| **割引後の価格**を「最安値」として載せてしまった | 同じラベルなら高い方（通常価格）を採る |
| **月額**39,600円を**一括**475,200円と同じ軸で並べた | 一括・月額・入学金を区別し、同じ種類の中だけで比べる |
| キャンペーンの申込期限「2週間以内」を受講期間として出しかけた | 期間の代表値は作らない。プランごとにしか持たない |

いま入っている自動チェック（ガード）は15種類ほどあり、
`npm test`（**447件**のテスト）で毎回確かめています。

### 確認できなかったときは空欄のままにする

無理に埋めず、理由を内部メモ（`review_flags`）に残します。現在の内訳は、
詳細ページを見に行った 112件、料金の範囲が限定的 47件、都道府県が未確認 115件、ジャンルの裏付けが弱い 3件。
**このメモは画面には出しません。** また、確認できない項目があっても掲載は止めません
（承認待ちの仕組みは意図的に持っていません）。

## 5. 載せるもの／載せないもの

- **自社で講座を提供しているスクールだけ**を載せる。他社の講座を集めたポータルやマーケットプレイスは対象外
  （マナビDX・ストアカが載って料金も期間も空欄になったため）
- **講座の写真やアイキャッチ画像は使わない。** 使うのはロゴ（ファビコン）だけ。
  著作権と、相手のサーバーに負担をかけないための判断
- **口コミの自動収集はしない。** 3サイト調べたところ、robots.txt で拒否されている／利用規約で商用利用が禁じられている
  などの理由があり、当面は口コミ無しで進める（仕組み自体は残してあり、全サイト `enabled: false` で1件も通信しない）
- **趣味寄り・中高生向けに見える講座も、ジャンル判定を通っていれば残す**（2026-09-08 の判断）。
  掲載範囲を絞ると決めるまでは、この判断を繰り返し蒸し返さない

## 6. 診断ウィザード（あなたに合う講座を探す）

トップから使える簡易診断です。質問は最大6問。

1. 学ぶ目的は？　2. 興味のあるジャンルは？　3. 経験レベルは？　4. 受講スタイルは？
5.（通学を選んだときだけ）どの都道府県で通いたい？　6. 給付金にこだわりたい？

点数の付け方は、目的が合えば +3、レベルがぴったり +2（近ければ +1）、受講スタイルが合えば +2、
給付金の条件が合えば +2、ジャンルの一致数で最大 +3。
**点数がまったくの同点のときだけ**、提携している講座を先に出します（提携の有無は点数そのものには影響しません）。

## 7. お金まわり（広告と提携）

### Google AdSense

- 広告枠は4か所（一覧の最上部／一覧の途中・6件ごと／一覧の最下部／講座の詳細ページ）
- **広告IDは姉妹2サイトと同じものを流用**している。そのぶん、どのサイトでいくら稼いだかは
  「サイト別レポート」で見る必要がある
- 審査用のタグは、トップ・FAQ・プライバシー・404の`<head>`に**固定で**書いてある
  （JSで後から読み込むと審査に通らなかった実績があるため）
- 現在は枠の表示が `enabled: true`。審査が通るまで広告は配信されないので空白が出るが、
  Tatsuroさんの了承のうえでこのままにしている
- **AdSense の状況**：「準備中」。不承認にはなっていないので、審査リクエストは押さずに結果を待つ

### 提携（アフィリエイト）

- トップの「おすすめ講座」枠は、**提携している講座だけ**を出す広告枠。必ず「PR」表示を付ける
  （2023年10月からのステマ規制のため）
- 提携が0件のときは枠ごと出さない。表示順は毎回ランダム
- **掲載するかどうか・掲載内容には、提携の有無はいっさい影響しない**。この説明はFAQとプライバシーポリシーにも書いてある

## 8. 学び直しガイド（記事）

現在3本。制度・支給率・上限額・日付は**厚生労働省の公式ページで確認できたものだけ**を書き、出典を載せています。
受給要件の細かい条件は公式ページで確認しきれなかったので書かず、ハローワークで確認するよう案内しています。

1. 教育訓練給付金とは？3つの種類と、対象講座の探し方
2. 社会人の講座選びで確認したい4つのポイント
3. オンライン講座と通学、どちらを選ぶ？

**増やすなら2〜3本ずつ。** 似た記事を急いで量産すると「中身の薄いページを大量に作っている」と
判断されるおそれがあるためです（姉妹サイトが実際にそれで不承認になりました）。

## 9. 検索エンジンに出す範囲

姉妹サイトが AdSense で「有用性の低いコンテンツ」と判定されたため、
**中身を確認できていないページは検索対象から外しています**（サイトには残します）。

- 説明文を公式サイトの本文から確認できなかった講座は `noindex`＋サイトマップから除外
- ジャンル別ページは、検索対象の講座が1件でも含まれるときだけ検索対象にする

線引きは `scraper/lib/indexing.js` の1か所だけで決めていて、テストが「詳細ページとサイトマップで
同じ線引きが使われているか」を見張っています。

（1件でも入れば即日次に戻り、どれだけ0件が続いても7日ごとに必ず再挑戦します）。

## 11. 公開のしくみ

- GitHub Pages（`main` ブランチのルート）＋ Cloudflare DNS
- **`main` に入った時点で自動的に公開**される。日次ワークフローは詳細ページ・サイトマップまで作り直してコミットするので、
  収集結果がそのまま公開ページに反映される
- 独自ドメインは `skillup-zukan.net`（apex のみ、`www` は未設定）
- Cloudflare は **DNS only（グレーの雲）**。オレンジの雲にすると証明書の発行が通らない
- 反映後の確認は `cd scraper && npm run verify-live`

## 12. 運用のルール（Tatsuroさんが決めたこと）

- 問い合わせ先はメールアドレスを掲載（フォームは作らない）
- 運営者自身のアクセスは計測しない（どのページでも `?ga=off` を一度開く。`?ga=on` で解除、`?ga=status` で確認）
- クラウド（スマホ・claude.ai/code）から作業でき、変更は PR で届く。**マージして初めて公開される**
- 掲載件数の表記は3サイトで揃える（「全国の講座を〇〇件掲載中！」）

### 人に確認すること／しないこと

**確認する**：これまでのルールで対処できない新しい種類の曖昧さ／データ構造そのものを変える判断／
お金・法律・利用規約に関わる判断／後から直すコストが高い決定。

**確認しない（そのまま進める）**：決まっているルールを新しいデータに当てはめること／
過去と同じパターンの問題を同じ方法で直すこと／テストやガードの追加／明らかなバグ修正。

## 14. これからの課題

- ジャンルの自動判定の精度は、日次ログを手がかりに**事後で**確認する（承認待ちの仕組みが無いため）
- 口コミをどうするか。再開するなら「各スクールから転載許可を得る」か「図鑑に投稿フォームを置いて自前で集める」の2択
- AdSense の審査結果待ち。通ったら、このサイト専用の広告ユニットを作って売上を分けて見るかを判断する
- 都道府県が未確認のまま載っている講座が115件ある。通学で探す人の役に立ちにくいので、拠点ページの巡回で減らしたい
